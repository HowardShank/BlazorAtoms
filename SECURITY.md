# Security Policy

## Supported Versions

Each `BlazorAtoms.*` package is versioned independently. Security fixes are made against the
latest published version of each package; older versions are not patched.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report it privately via [GitHub Security Advisories](https://github.com/HowardShank/BlazorAtoms/security/advisories/new)
for this repository, or contact [@HowardShank](https://github.com/HowardShank) directly.

Include:

- Which package(s) and version(s) are affected
- Steps to reproduce, or a minimal repro
- The potential impact

You should get an acknowledgment within a few days. If confirmed, a fix will be prepared and a
new package version published; you'll be credited in the advisory unless you ask not to be.
